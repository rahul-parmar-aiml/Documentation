Shopify Embedded App — TypeScript Framework Research

Best TypeScript framework for scalable Shopify embedded apps with a unified FE + BE stack

Recommendation: Use Remix — Shopify's officially backed framework. TypeScript end-to-end, single codebase, production-ready Shopify integrations out of the box.

✅ Why Remix Wins

1. Official Shopify Backing

Shopify ships and maintains @shopify/shopify-app-remix, their first-party Node.js package:

  • OAuth + session token authentication (no cookies — embedded-safe)
  • Webhook registration and verification
  • App Bridge v4 integration (mandatory since March 2024)
  • Shopify Admin GraphQL API client per-store, pre-authenticated

2. Unified TypeScript Codebase

Backend (loader / action functions) and frontend (React + Polaris) live in the same project. Define types once, share everywhere — no API contract drift.

3. Scalability Built-In

  • Session storage: Prisma adapter — swap SQLite (dev) → PostgreSQL (prod) with one config line
  • Multi-tenancy: Every Shopify store is an isolated session; the SDK enforces scoping automatically
  • Webhooks: Async-safe; offload long jobs to a queue
  • Performance: Streaming SSR keeps TTFB low at scale

4. GraphQL by Default

Shopify deprecated the REST API in October 2024. All new apps must use the GraphQL Admin API. The Remix package ships with a pre-authenticated GraphQL client per request — zero extra setup.

⚖️ Why Not the Alternatives

OptionVerdict
Next.js No official Shopify package. Requires manual OAuth, session, and App Bridge wiring. Only viable if team has strong Next.js expertise and accepts the extra setup cost.
T3 Stack (Next.js + tRPC + Prisma) Excellent type safety but community-only Shopify templates. tRPC adds learning curve with no advantage over Remix's native loaders/actions.
NestJS + Next.js Overengineered — two runtimes, two build pipelines, increased ops complexity. Reserve only for microservice-scale products.

🚀 Getting Started

# Install Shopify CLI and scaffold the Remix app
npm install -g @shopify/cli
shopify app create --template=remix

# What you get out of the box:
# - OAuth + session tokens
# - App Bridge v4
# - Polaris components
# - Prisma + SQLite session store
# - Webhook handler example
# - TypeScript throughout

For production, update prisma/schema.prisma datasource to PostgreSQL and set DATABASE_URL.
